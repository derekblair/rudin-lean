## Concrete mismatch checks

The inspected Lebl integral-limit declaration assumes and concludes `IntervalIntegrable ... volume`. Its name/comment about Riemann integration does not provide an equivalence to this repository's native `Rudin.PMA.Chapter06.RSIntegrable` and `RSIntegral`, defined from closed-cell Darboux sums. Chapter 7 must prove the native limit result or a full faithful equivalence first. Replacing that statement with a measure-integral theorem would change the contract.

The inspected Lebl derivative-limit declaration assumes `ContDiffOn ℝ 1` for each term. That is stronger than a source theorem assuming only differentiability. A Chapter 7 derivative interchange theorem must retain the actual weaker assumptions, domain endpoints, convergence at one point, and the exact uniform derivative condition. Taylor's separate [calculus API study](ch07-calculus-api.md) owns this bridge.

The current official [Mathlib Ascoli documentation](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Topology/ContinuousMap/Bounded/ArzelaAscoli.html), [Stone–Weierstrass documentation](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Topology/ContinuousMap/StoneWeierstrass.html), and [uniform derivative limits documentation](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Analysis/Calculus/UniformLimitsDeriv.html) confirm that these are established library topics. Actual implementation decisions must use the local pinned revision, not assume the moving documentation is identical.
